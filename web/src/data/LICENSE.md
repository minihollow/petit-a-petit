# Données

`verbs.json` (`scripts/build-verbs.mjs`), `words.json` et `../../public/lexicon.json` (`scripts/build-words.mjs`) sont générés à partir de :

- **Lexique 3.83** (formes conjuguées, phonologie, fréquences) : Boris New, Christophe Pallier et al., <http://www.lexique.org>,
  licence Creative Commons Attribution-Partage dans les mêmes conditions 4.0 (CC BY-SA 4.0).
  New, B., Pallier, C., Brysbaert, M., Ferrand, L. (2004). Lexique 2 : A New French Lexical Database.
  *Behavior Research Methods, Instruments, & Computers*, 36(3), 516-524.
- **Listes par thème, sens en turc et remarques** (`scripts/verbs-meta.json`, `scripts/words-themes.json`, `scripts/function-words.json`) : projet Petit à petit.

L'ensemble de ces données est distribué sous **CC BY-SA 4.0** : <https://creativecommons.org/licenses/by-sa/4.0/>.
